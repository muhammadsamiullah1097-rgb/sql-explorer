Why this exists — read this first

Learn SQL on data that actually matters.

🧩 The problem

SQL courses teach you on fake "employees" tables. You learn the syntax but never touch data that means something — and real datasets need database setup most learners don't have.

👥 Who it's for

Students, job seekers and analysts who want to learn SQL on data that actually matters — and teachers who need a zero-setup classroom tool.

🛠️ What you can do here

Learn mode: 10 guided queries with plain-English explanations. Analyst mode: a free SQL editor with schema browser, CSV export and query history. Data source tab: see exactly where every number came from.

Why it's different: no sign-up, no server, no setup — real SQL running in your browser on 12 real Pakistan indicators, 1960–2024 (population, income, inflation, literacy…), plus a Pakistan / India / Bangladesh table built for JOINs. Practice on the economy you live in, not a fictional company.

What is a database table? (30-second version)

Think of a table like an Excel sheet. Each column is a heading (like year, population). Each row is one line of facts. SQL is just the language you use to ask the sheet questions.

pakistan — 65 rows (one per year, 1960–2024), 12 columns: population, income, inflation, life expectancy…
countries — Pakistan, India & Bangladesh side by side, 4 headline numbers per year. Made for comparisons.
Empty cells (–) mean the World Bank simply has no data for that year. We show the gap honestly instead of guessing.
